# Support

This repository is a public demo of a Business Central Per-Tenant Extension (PTE) built on the [AL-Go for GitHub](https://github.com/microsoft/AL-Go) template. It is provided as-is for demonstration and learning purposes.

## How to file issues and get help

Please use the [GitHub Issues](../../issues) tab in this repository for bugs or questions about the sample.

This project is not a Microsoft product and is not covered by Microsoft Support.
