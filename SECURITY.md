# Security Policy

This repository is a public demo/sample app for Business Central and is not intended for production use as-is.

## Reporting a vulnerability

If you find a security issue in this sample (e.g. in the AL code or the AL-Go pipeline configuration), please open a [GitHub issue](../../issues) in this repository or contact the repository owner directly. Please do not include sensitive details in a public issue if the concern is exploitable.

This project follows no formal disclosure SLA; it is maintained on a best-effort basis.
